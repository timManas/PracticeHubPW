# PlayWright Practice Labs Demo

Just a demo project for educational purposes.

## Installation
1. Install node: npm init
2. Install playwight: npm init playwright@latest

### Prerequisites
None. Have fun 

## Running Tests
1. Execute all tests: npx playwright test


## Project Structure
Project is split up into:
1. data
2. fixtures
3. pages
4. playwright-report
5. test-results
6. tests
7. utils
